1 Get your export from Instagram

Instagram will email you a ZIP file. It can take anywhere from a few minutes to a few hours, depending on account size.

On your phone (app):

  1. Profile → tap ☰ (top right) → Accounts Center.
  2. Your information and permissions → Download your information.
  3. Pick the account, then Create export (or "Request a download").
  4. Choose Download to device, format JSON, date range All time.
  5. Under "Select information", untick everything except Followers and following — it keeps the file tiny and fast.
  6. Submit. Instagram emails you a link when it's ready.

On a computer: same path at accountscenter.instagram.com → Your information and permissions → Download your information.

Choose JSON, not HTML. HTML exports silently drop older rows from long lists, which makes people look like they don't follow you back when they do.

2 Import it

  1. Download the ZIP from the email — keep it zipped, don't unzip it.
  2. Open the tool and drop the ZIP on the big box (or tap it and pick the file).
  3. Parsing takes about a second for a normal account. A 500 MB export can take longer — leave the tab open.

The file is read by JavaScript inside this tab. There is no upload step, no account, and no analytics on that path — you can test it by turning off Wi-Fi after the page loads.

Open Export integrity under the list to see exactly which files were read, how many rows each held, and whether the follower list looks truncated. If Instagram's own insights page disagrees with the number of rows in the export, you get a warning — that is the honest case where a "not following back" entry might actually follow you.

4 Work the list

  • Open next & check off — opens the next unchecked profile in a new tab and marks it done, so you always come back to the right place.
  • The checkbox — click any row to mark it done/un-done by hand.
  • Hide checked — shrinks the list to what's left.
  • Copy usernames / CSV — take the list elsewhere.
  • Search — filter by any part of a handle.

Progress is saved in this browser, keyed to this export. Import a newer export and you start clean instead of inheriting stale check-offs. Reset clears check-offs for the current export.

This tool never unfollows anyone for you. Instagram has no public unfollow API, and any site claiming to do it is either scraping your password or breaking the rules. Open the profile, tap Unfollow, come back — that's the safe loop.

5 Find dead or deactivated accounts

An export is a snapshot of handles, not a live directory. If someone deleted or deactivated their account after it was captured, they still appear in your following list — and they can never follow you back.

Instagram only answers "does this profile still exist?" for a logged-in session. Logged out, every profile URL returns the same generic page, so there is nothing to check offline. Two ways to get the answer:

Option 1 — server check. Press Check these accounts in the tool. Only the handles on your list are sent to a small checker service, which asks Instagram and sends back exists / gone / unknown. Nothing else about you goes with it. Fastest, and it needs nothing from you.

Option 2 — run it yourself. Drag the button to your bookmarks bar and click it on instagram.com. It uses your own session and never touches our service.

  1. On the tool page, open Find dead or deactivated accounts.
  2. Drag the Check N accounts button to your bookmarks bar. (Bookmarks bar hidden? Ctrl+Shift+B on Windows, ⌘+Shift+B on Mac.)
  3. Go to instagram.com in the same browser, logged in.
  4. Click the bookmark. A panel in the corner counts up: gone / exists / failed, about one account per second.
  5. When it finishes it opens this page again with the results applied — dead accounts get a gone badge and an exists badge appears on the ones Instagram confirmed.

The checker only reads profile pages. It never follows, unfollows, likes, or messages. If you'd rather not run it, you can mark rows as gone by hand.

On a phone

  • The whole site works in mobile browsers — import, lists, search, CSV.
  • Request the export from the Instagram app, then open the emailed link and download the ZIP to your phone.
  • When the file picker opens, choose Downloads (Android) or Files (iOS) and pick the ZIP.
  • Bookmarklets don't run in mobile browsers and the Instagram in-app browser is worse. On a phone, tap a profile, and if you see "Sorry, this page isn't available", tap the 🚫 button on that row to mark it gone.
  • Instagram's in-app browser (the one inside the Instagram app) can't download files properly — open the link in Chrome or Safari instead of the in-app view.

Troubleshooting

"No follower or following list was found."
Your export didn't include those two sections. Re-request it and tick Followers and following.

"Could not find the followers list."
The ZIP contains only one side. That usually means the export was made with a custom selection — same fix.

It says someone doesn't follow me back, but I'm sure they do.
Three honest reasons, in order of likelihood: the export is a day or two old (people followed you in between); you imported an HTML export, which drops older rows, so check the integrity panel for a truncation warning; or the two lists were captured at different times inside one big export. Re-download in JSON format for an exact answer.

The numbers look smaller than my profile.
Instagram caps what it writes into exports for very large accounts. The integrity panel tells you when its own insights page disagrees with the row count.

Nothing happens when I drop the file.
Some browsers refuse drag-and-drop from certain folders. Click the drop box and use the file picker instead.

The bookmarklet does nothing.
Chrome blocks javascript: URLs pasted into the address bar; you must drag the button to the bookmarks bar and click it from there. On mobile, bookmarklets are not supported at all.
