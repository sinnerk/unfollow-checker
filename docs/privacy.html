Privacy

The whole point of this tool is that your data stays yours. Here is the literal truth, not a policy.

Your export never leaves the browser

The ZIP is opened by JavaScript running in your tab. There is no server component, no upload endpoint, no account, and no analytics. You can verify it: load the page, switch off your network, and import the file — it still works.

What is stored, and where

Check-offs and "gone" marks are saved in this browser's localStorage, keyed to a fingerprint of the export you imported. They are not synced anywhere and are not readable by other sites. Reset clears check-offs; Clear gone marks clears the other.

The dead-account checker

That one feature needs your Instagram session, because Instagram answers "does this profile exist?" only for a logged-in visitor. It works like this:

  • The check runs as a bookmarklet — a small script you click while you are on instagram.com. Your login stays in Instagram's own cookies.
  • This site never sees your password, your cookies, or your session. It only receives the list of handles that turned out to be gone, and only if the script hands it back to you.
  • The script is read-only: it fetches public profile metadata for the accounts in your list, at about one request per second. It never follows, unfollows, likes, messages, or posts.
  • The results are passed back in the URL fragment (#verify=…). Fragments are never sent to a web server — not to this site's host, not to anyone.

The optional server check

There is a second way to find dead accounts, and it is the only part of this site that talks to a server. It is off unless you click it:

  • We send only the Instagram handles from your "doesn't follow back" list — nothing else. No export, no file, no cookie, no account name of yours.
  • The service asks Instagram whether each profile still exists and returns one of three words per handle: exists, gone, unknown.
  • It caches those public answers (handle → exists) for a day so popular accounts aren't re-checked, and it logs aggregate counts only — no IP addresses, no per-visitor records.
  • It cannot see your list beyond the handles in that one request, and it cannot tell who you are.

If you'd rather not use it, the bookmarklet path does the same work inside your own logged-in tab and never contacts this service.

Third parties

No fonts, no analytics, no ad pixels, no third-party scripts on the page itself — the zip reader is bundled and served from GitHub Pages. The only outbound call the site can make is the handle check described above, and only when you press that button.

Links out

Opening a profile takes you to instagram.com, where Instagram's own privacy policy applies.
